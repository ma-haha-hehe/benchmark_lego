# 初版：第一次生成的数据与论文风格图片

- **任务本体：`tasks/`**。完整 400 个最初生成的任务，Tier 1–4 各 100 个；从原始生成备份恢复，未重新生成。
- **图片：`images/index.html`**。最初论文风格预览，24 个样例，每个 Tier 6 个。

图片目录中的 `sources/` 是这 24 个任务的检查副本；完整初版任务在 `tasks/`。`images/manifest.csv` 保存任务路径、种子和源 YAML 的 SHA-256，供核对图片与任务的对应关系。

本版保留最初规则，供历史对照，尚未采用后来调整的 Tier 2 朝向、简单布局、块数分布和 Tier 4 中心条件。当前脚本以最新版为准。

仓库根目录另有 `tasks/`：那是直接来自远端仓库的原始数据，不是这套第一次生成预览对应的任务。它保持原样保存。
