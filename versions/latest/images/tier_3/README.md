# Tier 3

四个 Tier 的主示例统一使用 target.png：论文风格固定方位角 -60°、仰角 25°。侧视、分层和中心检查仅作为单独的辅助视图，不替代主示例。

3–12 块，多块底层支撑通过上层桥接连接；所有上层砖的整个底面矩形都在底层整体包络内（允许贴边）。中心不要求重合。

统一图例和定义：../tier_definitions.html。洋红色是结构参考轴 G，紫色是底层包络，C 编号是砖中心，橙点是 Tier 4 合格上层中心。G 不表示重心；初始图使用料盘参考 P。

从 index.html 进入；overview.png 显示 12 个样例。每个任务使用实例 ID 命名的独立目录；文件名表示视角。source/ 是对应 YAML 检查副本。完整任务在 versions/latest/tasks/simple_shape_assembly/。
