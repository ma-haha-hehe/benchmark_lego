# Tier 4

3–12 块，至少一块上层砖的 XY 中心落在底层整体包络的边界上或外部。仅砖体伸出而中心仍在内部，不满足此规则。

统一图例和定义：../tier_definitions.html。洋红色是结构参考轴 G，紫色是底层包络，C 编号是砖中心，橙点是 Tier 4 合格上层中心。G 不表示重心；初始图使用料盘参考 P。

从 index.html 进入；overview.png 显示 12 个样例。每个任务使用实例 ID 命名的独立目录；文件名表示视角。source/ 是对应 YAML 检查副本。完整任务在 versions/latest/tasks/balanced_order_sensitive/。
